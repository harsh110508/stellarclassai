Is that point of light a star, or a whole galaxy?

In survey images, distant galaxies and nearby stars can both look like faint dots. StellarClass AI learns the difference from {{ "{:,}".format(metrics.dataset.n_total) if metrics else "" }} objects whose true class was measured from their spectra by the Sloan Digital Sky Survey. It then estimates the class of a new object from its brightness in five colour filters, plus its redshift when one is available.

How it works

  1. Real survey data

    {{ config.DATASET_NAME }} ({{ config.DATASET_RELEASE }}). Quasars are removed, leaving a binary star/galaxy task.

  2. Cleaning and features

    Invalid sentinel values are dropped. Colour indices such as g − r are computed from the magnitudes inside the model pipeline.

  3. Training and tuning

    A Random Forest is tuned with cross-validation and compared with Logistic Regression and a majority-class baseline.

  4. Honest evaluation

    Scores come from {{ "{:,}".format(metrics.dataset.n_test) if metrics else "held-out" }} test objects the model never saw during training.
